## コードスタイル
- インデントはスペース2つを使用してください。
- クリーンでシンプル、そして簡潔なコードを生成する
- スクリプトが読みやすく理解しやすいものであることを確認しましょう
- スクリプトの仕組みを理解するのに役立つコメントを追加してください
- 実行状況を提供するために簡潔でシンプルなエコー出力を生成する
- 不要なエコー出力や過度なログ記録を避けましょう
- 利用可能な場合は、静的解析にshellcheckを使用してください
- 変数は安全な展開を優先してください。変数参照は二重引用符で囲み、明確さのために必要に応じて`${var}`の形式を使用し、`eval`の使用は避けてください。
- スクリプトの先頭には、実行時のオプションを明示的に指定したシバン行を追加してください。
```bash
#!/bin/bash -ue
```
- 一時ファイルを使用する場合は、スクリプト終了時に必ずクリーンアップするようにしてください。
```bash
function cleanup() {
  # クリーンアップ処理をここに記述
}
trap cleanup EXIT ERR
```
- 以下のような記述は避けてください。
```bash
ls -a /tmp
status=$?
if [ $status -ne 0 ]; then
  echo "Error: Failed to list /tmp"
fi
```
- なるべく次のような簡潔で安全な記述を心がけましょう。
```bash
if ! ls -a /tmp; then
  echo "Error: Failed to list /tmp"
fi
```
- 配列、ハッシュ配列を用いる場合は declare を使用して明示的に宣言し初期化してください。
```bash
declare -a my_array=()
declare -A my_hash=()
```

# 文字コード
- 文字コードは UTF-8 を使用してください。
